Works on: Windows, Linux, Macos(not tested and no install script for macos).

This is an example for raylib(https://github.com/raysan5/raylib) which i did not make credit for that to raysan5
# What this can do:
 - U can press enter to display text.
 - Displays the fps under that it displays in a corner of your screen.
# How to use make:
 - Use `make Windows` to compile it for windows WARNING! only works if u use the default install path for raylib.
 - Use `make WindowsInstallUrl` to see the URL where u can install raylib
 - Use `make Linux` to compile on almost any Linux distro
 - Use `make LinuxInstallCommands` to list the installation commands to use on common Linux distro's installs gcc, raylib and pkg-config
 - Use `make WindowsRun` to run the program on Windows
 - Use `make LinuxRun` to run the program on Linux
